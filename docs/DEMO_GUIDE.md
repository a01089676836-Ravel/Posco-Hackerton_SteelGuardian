## 2. 시연 1: 컨베이어 실시간 연속 판정 (35초)

### 🎯 핵심 멘트 및 공학 팩트 가이드 (과장 금지)
* **처리 속도 표현**: 
  - ❌ *"초당 수 장의 초고속 처리"* (과대 표현 금지)
  - ⭕ **"이송 주기 0.2초 + AI 추론 0.3초 기반의 실시간 연속 판정 (초당 1~2장)"**
* **히트맵 시각화 정책**:
  - ⭕ **"정상(PASS) 부품은 공정 효율을 위해 서버가 히트맵을 의도적으로 억제하여 원본 이미지를 표시하고, 결함(REWORK / SCRAP) 발생 시에만 이상 결함 히트맵을 오버레이합니다."**
* **주요 UI 관찰 포인트**:
  1. **상단 배너**: `모델 상태 동기화 정상 (해시 일치: 4d11...)` 상시 확인.
  2. **이미지 캡션**: 프레임마다 실제 처리 시간(`Latency: 284ms` 등) 정밀 표시.
  3. **인터록 발동**: 치명 불량(SCRAP, Bent/Cracked) 유입 즉시 화면 상단에 빨간색 `[설비 인터록 ON: 라인 자동 정지]` 배너 표출.
  4. **2차 판정 대기**: 인간 협업(`HUMAN_IN_THE_LOOP`) 모드 작동 시 애매한 경계 영역 결함은 `MANUAL_REVIEW (2차 판정 대기)`로 안전 격리 집계.

## 3. 시연 2: 30초 신규 부품 고속 온보딩 CLI (25초)

### 🎯 실행 절차
```powershell
python onboard_new_part.py --part-name test_gear --data-dir data/onboard_sample --coreset-ratio 0.10
```
* **관찰 포인트**:
  - 정상 부품 단 20장만으로 백본 임베딩 추출 → Greedy Coreset 10% 압축 → 28.4초 만에 `test_gear.pt` 모델 및 `.meta.json` 생성 완료.
  - 심사위원 질의 포인트: *"기존 딥러닝은 수만 장의 불량 데이터와 수일간의 학습이 필요하지만, SteelGuardian은 Coreset 알고리즘으로 30초 안에 신규 규격을 즉시 현장 투입 가능합니다."*

## 4. 시연 3: 무중단 모델 핫스왑 & MES 감사 로그 (30초)

### ⚠️ 시연 진행 시 필수 주의사항 (대시보드 특성 반영)
* **대시보드 사이드바 클릭 금지**: 
  - 대시보드 화면 내 '모델 활성화' 버튼을 직접 클릭하면 Streamlit 프레임워크 특성상 전체 페이지가 재실행되며 가동 중이던 컨베이어 스트리밍 루프가 중단됩니다.
* **무중단 시연 공식 동선 (화면 분할 진행)**:
  1. 좌측 화면: 대시보드 컨베이어 실시간 스트리밍을 계속 가동 상태로 유지.
  2. 우측 터미널: 준비된 원클릭 트리거 스크립트 실행.
     ```cmd
     scripts\demo_hotswap_trigger.bat
     ```
     *(또는 PowerShell에서 `.\scripts\demo_hotswap_trigger.ps1` 실행)*
* **화면 실시간 반응 설명**:
  - 교체 호출 즉시 대시보드 상단에 1프레임 동안 `[모델 불일치 감지]` 경고가 나타난 후, 다음 프레임부터 새 모델 해시(`6da1b9d9...`)로 **`[동기화 정상]` 배너가 자동 갱신**되는 과정을 보여줍니다. (스트리밍 드롭 없이 즉시 인가).
  - 시연 모델 명칭: 너트 전경 마스크 채점 개선 모델(`metal_nut_fg`).
* **MES 감사 로그(Audit Log) 증빙 동선**:
  - 대시보드 UI의 감사 화면은 '검사 판정 이력'을 보여주는 화면이므로, 모델 활성화 이력은 별도 파일인 **[`logs/model_activation_audit.csv`](file:///C:/Users/wjswh/Documents/antigravity/posco_hackathon/logs/model_activation_audit.csv)**를 메모장이나 VSCode로 열어 보여줍니다.
  - 증빙 필드: 교체 시각(ISO 8601), 요청자 IP, 이전 모델 해시, 신규 활성 모델 해시(`6da1...`), 결과(`SUCCESS`).
* **시연 종료 후 원복**:
  - `scripts\demo_restore_default_model.ps1` 실행으로 기본 모델(`default`) 원복.

## 5. 질의응답 핵심 방어 수치 (SSOT 불변 기준)

1. **불량 유출 건수**: 
   - 115장 전수 데이터 및 5-Seed 평가 기준 **Recall 97.85% (FN = 2건: `scratch/000.png`, `color/004.png`)**.
   - 안전 모드(`SAFETY_FIRST`) 적용 시 **Recall 100.00% (FN = 0건)**.
2. **슬라이드 13 LRU 캐시 15MB / 50ms**:
   - 15MB: ResNet18 Layer2+3 10% Coreset 패치 데이터 실측 크기 (실제 `models/memory_bank.pt` 파일 크기 **9.6MB**).
   - 50ms: 로컬 NVMe SSD에서 9.6MB 모델을 메모리로 로드할 때의 벤치마크 실측치 (**42.1ms ~ 49.8ms**).
