## 4. `memory_bank.meta.json` 정정 근거

메타 대조를 추가하자 실제 기본 모델이 거부되었다. 기록된 해시가 실제 파일과 앞 12자리만 같았기 때문이다.

| 구분 | SHA256 |
|---|---|
| 기존 메타 기록값 | `4d118c709f018d963840742f10b8cf8b5bc08b982162985160b73c434220b30d` |
| 실제 파일 | `4d118c709f018279439869152887ee64adfba992356f26b01c928583a6569949` |

- `.pt`가 맞다고 판단한 근거는 다음과 같다. 네 role 폴더의 `.pt` 해시가 서로 같고, `evaluation.json`의 `model_hash`가 앞 12자리와 일치하며, 평가 임계치 0.4362와 인덱스 검증 테스트도 통과한다.
- 원본 생성 스크립트가 없어 **기존 값이 왜 생겼는지는 확인하지 못했다.**
- 이 파일은 Role 1 산출물이므로 김지민·차주현 님 확인이 필요하다.

## 5. 남은 위험과 미검증 항목

| 항목 | 내용 |
|---|---|
| **부하 성능** | 2회 비교에서 오류는 0건이나, 평균 +4.6%, P95 +11.4% 차이가 회차 간 편차와 겹쳐 영향 유무를 **판단 보류**했다 (작업 기록 04) |
| **#2 잔여 위험** | `patchcore_engine.py:99`는 여전히 `weights_only=False`다(Role 1 담당). 서버 시작 시 기본 모델은 검사하지 않으며, 검사와 재로드 사이에 파일이 바뀌는 경우도 코드 실행 자체는 막지 못한다 |
| **온보딩 모델 호환성** | `onboard_new_part.py`가 없는 `evaluate_benchmark.py`를 가져오려다 실패해 실제 산출물로 시험하지 못했다. 저장 코드를 읽은 결과 텐서와 기본 타입만 사용해 호환될 것으로 **판단**한다 |
| **해상도 한도** | 16MP 이내 이미지는 약 7초까지 걸려 대시보드 타임아웃 5초를 넘을 수 있다. 현장 해상도에 맞춰 `MAX_IMAGE_PIXELS`를 조정해야 한다 |
| **대기 스레드** | 대기 요청이 워커 스레드를 점유한다. 동시 40건을 넘으면 다른 API도 영향을 받을 수 있다 (코드에 `ponytail` 주석으로 표시) |
| **chunked 업로드** | `Content-Length` 없는 대용량 요청은 임시 파일로 저장된 뒤 거부된다 |
| **환경변수 적용** | `setup_and_run.bat`로 실행하면 `.env`가 적용된다(작업 기록 06). `uvicorn`을 직접 실행하면 OS 환경변수로 설정해야 한다 |
| **실행 범위** | Python 3.12, `.bat` 스크립트 전체 흐름, 실제 대시보드와의 연동은 시험하지 않았다 |
| **되돌리기** | git이 없다. 수정 전 `server.py`, `audit_logger.py`는 role_4에 동일한 파일이 남아 있지만, 임의로 수정될 수 있으므로 영구 백업은 아니다 |
