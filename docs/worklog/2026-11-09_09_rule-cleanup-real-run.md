## 3. 실제 실행 검증

임시 복사본에 role_2 파일과 role_4 `app.py`를 합치고, `.venv`와 `wheels/`가 없는 상태에서 `setup_and_run.bat`을 실제로 실행했다. 브라우저가 열리지 않도록 `STREAMLIT_SERVER_HEADLESS=true`를 설정했다.

| flip 이미지 (`SAFETY_FIRST`) | SCRAP, 인터록 켜짐, 점수 0.8982 |
| good/000 (`SAFETY_FIRST`) | PASS, 점수 0.361 |

- 로그의 `Input redirection is not supported`는 시험에서 표준 입력을 막아 `timeout` 명령이 낸 메시지다. 실제 콘솔 실행과는 무관한 것으로 판단하지만 콘솔에서 직접 확인하지는 않았다.
- 첫 시도는 시험 도구의 인자 전달 오류로 스크립트가 실행되지 않았다. 스크립트 결함이 아니다.
