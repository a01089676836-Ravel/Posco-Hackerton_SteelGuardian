## 2. 오프라인 설치

임시 복사본(role_2 파일 + role_4 `app.py`)에서 진행했다. 프로젝트 폴더에는 설치하지 않았다.

| 항목 | 결과 |
|---|---|
| `pip download -r requirements.lock.txt` | 111초, 104개 파일(wheel 103개, `FrEIA-0.2.tar.gz` 1개), 365MB |
| `setup_and_run.bat` 실제 실행 (`.venv` 없음, `wheels/` 있음) | `py -3.12` 자동 선택, `--no-index` 설치 후 서버·대시보드 기동까지 154초 |
| 잠금 파일 대조 | 고정 버전 104개 중 불일치 0건, `pip check` 이상 없음 |

- 다운로드는 인터넷이 필요하다. 설치는 `--no-index`로 `wheels/`만 사용했으나, 네트워크를 물리적으로 끊고 시험한 것은 아니다.
- `FrEIA`는 wheel이 없는 소스 배포본이지만 이 PC에서는 설치됐다.
- `wheels/`는 용량이 커서 프로젝트 폴더로 옮기지 않았다.

## 4. 판정과 부하

**실제 이미지 92장 판정 분포는 작업 기록 08의 Python 3.13 결과와 모든 칸이 같다.**

| 항목 | 결과 |
