### [00:40 ~ 01:40] 2. 핵심 아키텍처 및 4대 기술 차별점 (60초)
> "저희 시스템의 4대 핵심 기술을 말씀드리겠습니다.  
> 
> 첫째, **PatchCore 원논문 Eq. 6·7 정밀 구현**입니다. 무거운 외부 프레임워크에 의존하지 않고 순수 PyTorch로 ResNet18 중간 계층의 국소 패치 특징을 추출해 Coreset 메모리 뱅크를 구축했습니다. 특히 원논문 7번 식인 근방 9개 이웃의 메모리 밀도 재가중식을 적용하여 경계 결함의 분별력을 극대화했습니다.  
> 
> 둘째, **무누수 3-Tier 공정 안전 엔진**입니다. 단순 불량 점수에 의존하지 않고 결함 면적과 피크 패치 거리를 결합하여 PASS, 안전 재작업인 REWORK, 즉시 폐기인 SCRAP으로 자동 분기합니다. 특히 PASS 판정 시에는 붉은 히트맵을 자동으로 억제하여 조업자의 시각적 혼선을 원천 차단했습니다.  
> 
> 셋째, **30초 Zero-Training 온보딩과 무중단 핫스왑**입니다. 새로운 규격의 부품이 들어와도 GPU 역전파 학습 없이 정상 사진 20~30장만 넣으면 16.8초 만에 새 부품 모델을 자동 생성합니다. 이를 라인 정지 없이 REST API(`POST /v1/models/activate`)를 통해 락 기반으로 원자적 교체하며, SHA256 불일치나 데이터 누수가 감지되면 즉시 거부하고 롤백합니다.  
> 
> 넷째, **MES 동시성 감사 추적 및 100% 오프라인 완결**입니다. 멀티프로세스 환경에서 파일 락으로 200건 동시 요청 중 단 1건의 유실 없이 이력을 기록하며, 외부 CDN이나 텔레메트리 없이 단독 실행됩니다."

> 
> 넷째, **연속 가동 안정성**입니다. 200건 연속 부하 스트레스 테스트 결과 에러율 0.00%, 메모리 누수 0(-8.5MB), MES 감사 로그 200건 1:1 무유실 매칭을 검증했습니다."

> 반면 스크래치나 색상 결함은 'REWORK'로 분류되어 연마 라인으로 이송되며, 심각한 균열이나 체결 나사 휨 결함은 'SCRAP'으로 즉각 적색 경보와 비상 인터록이 발령됩니다.
